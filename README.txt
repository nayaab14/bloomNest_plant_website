BLOOMNEST PLANT WEBSITE
=======================

Pages included:
- index.html   (Home page)
- plants.html  (Plant collection)
- care.html    (Plant care tips)
- about.html   (About the website)
- contact.html (Contact form demo)

Folders:
- css/style.css  = styling and responsive design
- js/script.js   = simple contact form interaction
- images/        = folder reserved for your own downloaded images

HOW TO OPEN LOCALLY
1. Extract the ZIP file.
2. Open the BloomNest_Plant_Website folder.
3. Double-click index.html.
4. Use the navigation menu to open the other pages.

IMPORTANT
- Bootstrap CSS and JavaScript are loaded from a CDN, so internet is needed for Bootstrap styling and the mobile menu.
- Plant photos are loaded from Unsplash URLs, so internet is needed to show them.
- The contact form is a front-end demo. It does not send email or save messages.
- To use your own local images, put them in the images folder and update the image src in the HTML files.
- To publish on GitHub Pages, upload all files and folders while keeping the same structure.
